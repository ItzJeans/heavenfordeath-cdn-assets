Heaven for Death — Web Port

This is a browser-based port of Heaven for Death, a Bocchi the Rock! fan game. This project makes the game playable from a web browser/single file without requiring players to install the original game locally.

How It Works

The web port uses a single HTML launcher together with the original game engine and assets. The launcher loads the game's files from an npm package delivered through jsDelivr.

Game launcher: HTML, CSS, and JavaScript.

Asset hosting: npm package heavenfordeath-assets-itzjeans.

Content delivery: jsDelivr CDN.

Internet connection: Required while playing, because the game loads its assets from the CDN.

The asset package is currently pinned to version 1.0.1 so the web port uses a consistent set of game files.
