HEAVEN FOR DEATH - JSDELIVR ASSET MIRROR

1. Create a new PUBLIC GitHub repository named: heavenfordeath-cdn-assets
2. Extract this ZIP and upload its CONTENTS to the root of that repository.
   The root should contain audio/, css/, data/, fonts/, icon/, img/, and js/.
3. Wait for GitHub to publish the main branch.
4. In heavenfordeath-single-file.html, replace YOUR_GITHUB_USERNAME with your GitHub username.
5. Open the HTML on a web host or locally with an internet connection.

The trimmed mirror keeps all seven language data folders, all game images,
the four fonts selected by the launcher, and OGG files referenced in the
project source/data. It excludes unreferenced OGGs, unused font families,
the disabled Live2D folder, and development-only backups.
